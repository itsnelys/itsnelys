I create games, creative tools, and interactive worlds where gameplay engineering, technical art, and production workflows work as one. My projects range from an offline-first creative suite for game makers to Minecraft mods, sandbox systems, and reusable 3D resources.

## What I work on

- **Game development** — gameplay systems, progression, tools, procedural worlds, and player-driven experiences
- **Creative software** — focused desktop tools for pixel art, 3D modeling, animation, sound design, and project management
- **Technical art & 3D** — reusable assets, UV workflows, rigs, animation pipelines, and implementation-ready resources
- **Modding & sandbox development** — Java and gameplay projects for Minecraft, Arma, and community-driven games

## Pandora Interactive suite

An offline-first Windows toolkit built for creating game assets—from image editing and pixel art to 3D models, animation, and sound. The applications share a consistent interface, themes, languages, update system, and workflow. Source code is private; official Windows builds and release notes are public.

> **Now available: [Amethyst 1.0.0](https://github.com/itsnelys/Amethyst-Releases/releases/tag/v1.0.0)** — paint pixels, draw vectors, edit typography, and trace images in one offline-first workspace for Windows.

## Games & worlds

- **Grimward** — a dark-fantasy sandbox RPG in development, built around procedural worlds, exploration, modular gameplay systems, and stories shaped by player choices
- **Pandora Interactive** — an independent creative practice developing games, tools, and immersive worlds through a combined technical and artistic approach

## Selected public work

- **Iris Minecraft suite** — Java mods for Minecraft 1.21.1 / NeoForge: [IrisCore](https://github.com/itsnelys/IrisCore) provides the shared interface, HUD, settings, and key bindings; [IrisVision](https://github.com/itsnelys/IrisVision) adds item browsing, recipes, favorites, inventory search, and detailed tooltips; [IrisV](https://github.com/itsnelys/IrisV) is the standalone catalogue and in-game information project
- **Gameplay tools** — [AirLock](https://github.com/itsnelys/AirLock), [Autochest](https://github.com/itsnelys/Autochest), [LightDetector](https://github.com/itsnelys/LightDetector), and [AutoCloseDoors](https://github.com/itsnelys/AutoCloseDoors)
- **Modding & missions** — [Arm3Mission](https://github.com/itsnelys/Arm3Mission)
- **3D resources** — [3D_templates](https://github.com/itsnelys/3D_templates)

## Approach

I value clear systems, practical production workflows, and creative direction that supports play. Whether I am extending an existing game, building a specialized tool, or developing an original world, I aim to make the technical and visual sides feel inseparable.
